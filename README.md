# atrium

A private, single-operator agentic personal assistant, built as a Go
application with an embedded web UI and a NixOS service module.

- [Vision](docs/vision.md): the application's goals.
- [Application context](context.md): current behavior, accepted direction,
  and open decisions.
- [Development rules](AGENTS.md): constraints for changes.
- [Wayfinder map](https://github.com/jeiang/atrium/issues/15): feature plans.
