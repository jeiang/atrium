# Configuration reference

Generated by `just settingsgen`. Do not edit.

## Host configuration

The file named by `ATRIUM_HOST_CONFIG` is TOML with one table per module and an optional `[connections.<id>]` table. Unknown keys are refused. A host value is read-only in the application: `atrium settings set` and the Settings pages refuse it. Precedence: environment variable, host file, default.
