# Host environment variables

Generated by `just settingsgen`. Do not edit.

The file named by `ATRIUM_HOST_CONFIG` is TOML with one table per module and an optional `[connections.<id>]` table. An environment variable overrides that file. Host secret inputs accept only a `_FILE` variable naming a file whose trimmed contents are the value. Operator settings are stored in the database and are not set from the environment; a cut-over operator or tuning key is refused with its destination.

| --- | --- |

| `ATRIUM_CONFIG` | path of the legacy pin file; cut-over keys are refused |
| `ATRIUM_INITIAL_TZ` | time zone stored as the operator `tz` value when a fresh database has none |

| `ATRIUM_CACHE_DIR` | path of the message cache |
| `ATRIUM_DB_KEY` | database key as 64 hex digits |
| `ATRIUM_DB_KEY_FILE` | path of a file holding the database key |
| `ATRIUM_PUBLIC_HOST` | the one Host header the public listener accepts |
