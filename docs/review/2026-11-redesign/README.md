# Redesign plan, November 2026

This folder holds the plan for the atrium redesign: a new Svelte client beside the old UI, the core object merges, the apps split and the removal of the old UI.

| File | What it is |
|---|---|
| [decisions.md](decisions.md) | The operator's decisions D1 to D44, from four grilling rounds |
| [design-spec.md](design-spec.md) | The final design spec for the new client: tokens, components, layout and interaction rules, acceptance checks |
| [implementation-plan.md](implementation-plan.md) | The phased build P0 to P16: rules for the whole build, phases, dependencies, traceability, stop points and deployment |
| [issue-index.md](issue-index.md) | One row per issue: 17 epics and 119 slices |

GitHub issues #825 to #965 are generated from the issue index, one issue per row.

Ids such as `r4 N2`, `R1.47`, `C-28` or `rev 7` refer to research notes kept outside the repository. Each plan row restates what it needs from them.

Where the build stands is tracked in the issues, not in this folder.
